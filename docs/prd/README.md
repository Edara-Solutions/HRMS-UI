# PRDs — HRMS Frontend

Product Requirement Documents. Each PRD (`NNNN-slug.md`) fully specifies a piece
of work — problem, solution, user stories, and implementation/testing decisions
— from which independently-grabbable issues are derived in
[`../issues/`](../issues/README.md).

> **Flow:** PRD (here) → vertical-slice issues (`../issues/`) → implementation.
> An agent implementing an issue reads the issue *and* its parent PRD.
